# Changelog

All notable changes to this project are documented here.

## 0.1.0

Initial Vue implementation of the DocSearch 5.1 keyword-search experience.

- Vue 3 JSX modal, search button, result screens, and imperative lifecycle.
- Hierarchical results, safe highlighting, result badges, and query suggestions.
- Multi-index search, facet controls, Algolia Insights, and customization hooks.
- Recent and pinned searches with localStorage hardening.
- Keyboard, focus, touch, mobile viewport, theme, and portal support.
- VitePress compatibility for legacy options, navigation, and hit rendering.
- Production builds without React, Preact, or Ask AI runtime code.
